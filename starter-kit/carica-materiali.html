Strumenti per gli insegnanti

Invia i materiali della tua classe

Hai due modi per consegnarci i materiali prodotti dalla classe — scegli quello più adatto a quello che vuoi inviare.

☁️
Caricamento diretto di

Foto, audio e video

Usa il modulo qui sotto per caricare i file multimediali della classe: ricevi subito gli URL pronti da inserire nel file HTML della tua via. Le immagini vengono ridimensionate e ottimizzate in automatico.

Una volta inseriti gli URL nel file HTML, inviaci il file completato via mail al passo 5 — ci pensiamo noi a pubblicarlo.

Formati: JPG, PNG, GIF, WebP, MP3, WAV, MP4, WebM…

📦
In alternativa

Tutto in un archivio ZIP

Se preferisci raccogliere HTML e media in un unico archivio compresso, scrivici direttamente a viapervia.education@gmail.com allegando il file .zip — pubblichiamo noi il contributo.

Usa questa opzione anche per inviarci file in altri formati non supportati dal caricamento diretto.

Immagini, audio e video · Più file contemporaneamente

Formati accettati: immagini (JPG, PNG, GIF, WebP…), audio (MP3, WAV, OGG…), video (MP4, WebM…).
Dimensione massima: 50 MB per le immagini · 500 MB per audio e video.
Per ZIP e HTML usa invece l'invio via e-mail (vedi sopra).
3 · Carica
URL dei file caricati
4 · Inserisci gli URL nel file HTML

Copia gli URL ottenuti al passo 3 e incollali nel file index.html della tua via, sostituendo i segnaposto della galleria (gallery-placeholder) o i valori degli attributi src delle immagini e dei tag audio/video.

Se hai dubbi su dove inserire gli URL, consulta la guida per insegnanti.

5 · Invia il file HTML completato

Allega il file index.html aggiornato alla mail e invialo: pubblichiamo noi il contributo sul sito. Il pulsante qui sotto apre una mail precompilata con oggetto e destinatario già impostati.
